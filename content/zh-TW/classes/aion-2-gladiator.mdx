## 職業定位：Aion 2 劍星有何獨特之處？

傳統 MMORPG 中的戰士定位通常分為兩大原型：持盾防禦的壁壘與衝鋒陷陣的狂戰士。在《Aion 2》的世界中，守護星（Templar）負責擔任吸收傷害的頂級主坦克，而劍星則將純粹的侵略性轉化為對戰場的強大控場力。

劍星身穿重型金屬板甲，能夠承受大量物理打擊而不失擊殺能力。其核心優勢在於極高產出的物理範圍傷害、長攻擊距離以及致命的擊倒連招。在開放世界的混戰中，無拘無束的劍星宛如攻城巨槌，能輕易撕裂敵方後排並擊潰密集的脆弱法系職業。

下表展示了劍星與遊戲中其他核心近戰及物理戰鬥職業的對比：

| 職業原型 | 護甲類型 | 主要戰鬥定位 | 標誌性優勢 | 機動性與攻擊距離 |
| :--- | :--- | :--- | :--- | :--- |
| **劍星** | 板甲 | AoE 鬥士 / 副坦克 | 持續性多目標輸出與擊倒控場 | 中等機動性，廣範圍近戰攻擊 |
| **守護星** | 板甲 / 盾牌 | 主坦克 / 防護者 | 傷害減免、嘲諷、拉人控場 | 低機動性，防禦性突進接近技能 |
| **殺星** | 皮甲 | 單體爆發輸出 | 潛行、眩暈、急速背刺 | 高機動性，貼身近距離 |
| **弓星** | 皮甲 | 遠程物理輸出 | 陷阱、風箏拉扯、狙擊暗殺 | 高機動性，長距離遠程 |

殺星擅長在暗處單點刺殺，而 **Aion 2 劍星** 則在混亂中大放異彩。當多名敵人聚集時，劍星憑藉大範圍橫掃劈砍，輸出傷害將呈指數級倍增。

## 武器選擇：戰戟、大劍與雙持

武器的選擇直接決定了你的戰鬥風格。與綁定單一裝備配置的職業不同，劍星擁有全遊戲最廣泛的物理武器庫。深入理解各類武器的傷害特性、攻擊速度與暴擊屬性，是針對特定戰鬥自訂配置的關鍵。

```
戰戟（爆發與擊倒）  <--->  雙持（快速單體輸出）
             \                      /
              \                    /
               大劍（均衡型）
```

### 戰戟（Polearms）：範圍輸出與擊倒之王
戰戟始終是劍星最具代表性的招牌武器。它具備最高的單次揮擊上限傷害、極長的攻擊距離以及最高的先天擊倒機率。雖然最小傷害與最大傷害之間的浮動較大，但一旦戰戟觸發暴擊，便能輕易碾碎常規敵人。

### 大劍（Greatswords）：穩定可靠的均衡力量
大劍捨棄了戰戟波動劇烈的傷害峰值與稍慢的攻速，換取了更平穩的基礎傷害與更高的基礎命中率。大劍提供穩定的招架機率與更流暢的動作收招後搖，非常適合追求穩定輸出、不想依賴隨機傷害上限的玩家。

### 雙持（長劍與短劍）：快速撕裂單體目標
在面對範圍橫掃價值有限的副本首領戰時，社群數據顯示雙持雙長劍或長劍配短劍能帶來更優異的持續單體輸出（DPS）。雙持大幅提升普攻頻率，迅速觸發武器命中被動效果，並減少快速連續打擊時的動作僵直。

| 武器配置 | 傷害浮動穩定性 | 暴擊倍率 | 擊倒 / 跌倒潛力 | 最佳應用場景 |
| :--- | :--- | :--- | :--- | :--- |
| **戰戟（雙手）** | 浮動大（上限極高 / 下限偏低） | 極高（1.8x - 2.0x） | 最大化 | 多人 PvP、AoE 刷怪清怪 |
| **大劍（雙手）** | 中等（基準傷害穩定） | 高（1.5x - 1.7x） | 中等 | 單人升級、小型遭遇戰 |
| **雙長劍** | 穩定（波動極小） | 中等（1.4x） | 偏低 | 副本首領單體輸出 |
| **長劍 + 短劍** | 穩定（高攻擊頻率） | 高暴擊率 | 極小 | 依賴暴擊觸發特性的流派 |

## 核心技能機制、連招與控場技巧

**Aion 2 劍星** 的戰鬥核心圍繞著異常狀態連招展開。與按部就班按固定順序施放的技能迴圈不同，劍星的攻擊連招極度依賴對觸發機制（Proc）、招架以及敵方受控狀態的即時反應。

### 異常狀態優先級：擊倒循環
你的核心進攻基石在於**跌倒 / 擊倒（Stumble / Knockdown）**機制：

1. **先手突擊：** 拉近距離並施加物理減益（Debuff）或流血效果。
2. **擊倒觸發：** 施放強力的戰戟技能將目標直接擊倒在地。
3. **倒地處決追擊：** 觸發僅能在目標倒地狀態下啟動的條件式處決技能。
4. **後續橫掃收尾：** 當目標起身時，銜接範圍橫掃技能，同時打擊目標及其周圍試圖支援解圍的隊友。

| 技能類型 | 戰術目標 | 資源 / 觸發條件 | 核心效果 |
| :--- | :--- | :--- | :--- |
| **位移接近** | 迅速接近遠程目標 | 中等冷卻時間 | 爆發性移速提升、向前突進 |
| **廣角橫掃** | 傷害多個相鄰敵人 | 魔力 / 能量 | 弧形範圍物理傷害，附加流血 |
| **地震重擊** | 強力硬控場 | 連招階段 2 | 高機率擊倒最多 3 名目標 |
| **倒地處決** | 最大化爆發傷害 | 目標必須處於倒地狀態 | 額外暴擊傷害加成，無視部分護甲 |
| **狂暴姿態** | 自我增益爆發技能 | 長冷卻時間 | 大幅提升物理攻擊力，降低自身防禦 |

熟練掌握動作收招幀（Recovery Frames）至關重要。資深玩家會利用微小的移動輸入取消雙手戰戟後搖較長的收招動作，藉此在目標處於擊倒狀態的有限空檔內最大化輸出傷害。

## PvE 副本攻略 vs. PvP 大規模戰場

劍星的作戰方式會依據你身處結構嚴謹的副本挑戰還是混亂的大規模陣營戰而產生巨大變化。

### PvE 策略：高效率清怪控場
在團隊 PvE 中，**Aion 2 劍星** 主要扮演精英小怪群清理者與次要副坦克的角色。當大量副本小怪刷新時：
- 與守護星緊密配合，確保將目標集中聚怪。
- 走位至怪群側翼或後方，使大範圍橫掃能覆蓋怪群核心區域。
- 在開啟攻擊姿態爆發之前，預先輪流開啟防禦冷卻技能，確保自身承受的次要傷害不會造成治療者的過大壓力。

### PvP 策略：撕裂敵方後排
在開放世界與深淵空戰中，劍星是敵方小隊必須高度提防的高優先威脅。獨自衝入組織嚴密的敵陣只會讓你被無情風箏並迅速集火擊殺。相反地，應尋找魔道星與治癒星分心時的空檔，果斷切入密集的後排群體。一次時機精準的範圍橫掃搭配擊倒觸發，能瞬間瓦解敵方隊伍的陣形。

下表對比了這兩種模式下的流派構建與戰術優先級：

| 戰略維度 | PvE 團隊副本 | 開放世界與大規模 PvP |
| :--- | :--- | :--- |
| **首選武器** | 雙持（首領戰） / 戰戟（小怪群） | 專注使用戰戟（追求攻擊距離與擊倒效果） |
| **姿態側重** | 持續傷害與護甲穿透 | 移動速度、控場抗性、爆發力 |
| **目標優先級** | 密集的常規小怪群；首領弱點判定點 | 敵方治療者（治癒星）與玻璃大砲法系職業 |
| **生存手段** | 降低仇恨增益與持續生命吸取 | 解控藥水與屏障防護增益 |
| **走位定位** | 位於首領側翼；在治療陣內相對定點輸出 | 位於前線側翼；保持高速移動與不斷調整站位 |

## 推薦屬性與裝備養成路線

培養一名強大的 **Aion 2 劍星** 需要在物理擊殺能力與足夠的近戰生存韌性之間取得平衡。副屬性選取失誤可能導致角色雖然傷害高卻在接近敵人前暴斃，或者雖然防禦堅固卻缺乏瞬間爆發帶走敵人的輸出。

### 屬性優先級
1. **物理致命一擊（Physical Critical Strike）：** 核心進攻首選。暴擊可觸發極高的傷害倍率，並大幅提高觸發擊倒反應的機率。
2. **物理攻擊力（Physical Attack）：** 提供所有技能傷害倍率與普通攻擊的基礎數值加成。
3. **命中（Accuracy）：** 在 PvP 中至關重要，可避免高傷害技能被殺星與弓星等敏捷職業格擋、招架或閃避。
4. **生命上限（Max HP）與物理防禦（Physical Defense）：** 主要由金屬板甲裝備提供；是承受團隊戰鬥壓力時不可或缺的生存底線。

| 屬性類別 | 優先等級 | 目標閥值 / 基準 | 核心理由 |
| :--- | :--- | :--- | :--- |
| **物理致命一擊** | 第一梯隊（必備） | 達到當前等級區間的軟上限（Soft-cap） | 最大化擊倒觸發率與極限爆發潛力 |
| **命中** | 第一梯隊（必備） | 匹配同階裝備的平均迴避與格擋值 | 確保關鍵爆發技能命中無誤，避免偏斜落空 |
| **物理攻擊力** | 第二梯隊（高級） | 暴擊達標後主力堆疊 | 全面提升所有範圍技能連招的基礎傷害 |
| **生命值（HP）** | 第二梯隊（高級） | 在防具魔石孔位中均衡分配 | 防止在被硬控場期間遭到敵方瞬間集火秒殺 |
| **招架** | 第三梯隊（情境選用）| 雙手武器自帶的次要防禦加成 | 在承受打擊時觸發反擊連招機制 |

在裝備魔石鑲嵌方面，資深老玩家普遍建議優先鑲嵌物理致命一擊魔石直至達到穩定臨界值，隨後根據主攻競技 PvP 還是副本農怪，在剩餘孔位中補滿純物理攻擊力或生命力魔石。

## 關於 Aion 2 劍星的常見問題

### Aion 2 劍星適合新手玩家嗎？
適合。劍星的核心機制直觀清晰，擁有厚重的重甲防禦，單人刷怪能力也極為出色。雖然掌握卡刀消後搖技巧與高階 PvP 擊倒時機需要一定練習，但新手玩家在練級與開荒過程中會感到非常順暢且容錯率極高。

### 在 Aion 2 中我該選擇劍星還是守護星？
如果你渴望成為團隊中無可替代的核心主坦克、用盾牌保護隊友並透過嘲諷掌控戰局，請選擇守護星。如果你追求高額傷害、大範圍斬擊以及充滿進攻侵略性的前線肉搏體驗，請選擇 **Aion 2 劍星**。

### Aion 2 劍星可以在副本中擔任主坦克嗎？
在常規升級副本與中低難度內容中，經驗豐富的劍星只要妥善管理防禦冷卻技能，完全可以勝任副坦甚至拉穩仇恨抗怪。然而在終局高難度團隊副本與困難模式首領戰中，由於守護星具備更頂級的減傷機制與專屬仇恨製造技能，依然需要專職守護星擔任主坦。

### 劍星使用哪種武器傷害最高？
對於多目標爆發傷害與 PvP 對決，戰戟憑藉頂級的暴擊倍率與擊倒潛力能打出最高的瞬間爆發。而在長時間的持續單體首領戰中，雙持長劍或短劍在漫長的輸出過程中往往能提供更穩定且更高的每秒總傷害。
