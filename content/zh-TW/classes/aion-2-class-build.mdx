## 前線巨擘：劍星與守護星流派配裝

前線戰士掌握著每場交鋒的節奏。雖然這兩個職業都穿戴金屬防具，但兩者在屬性優先級與戰術職責上截然不同，分別偏重攻擊性控場與極致傷害減免。

### 劍星流派最佳化

劍星是一名具備毀滅性打擊力的進攻型近戰鬥士，能輕易撕裂敵群。在構建以進攻為主的 **aion 2 class build** 時，應優先堆疊「物理致命打擊」與「物理攻擊力」，以將範圍橫掃與擊倒連招的威力發揮到極限。

*   **主要屬性：** 物理致命打擊 > 物理攻擊力 > 命中 > 生命力上限
*   **核心烙印技能：** 地震波動 (Earthquake Wave)、順劈精通 (Cleave Mastery)、狂氣光環 (Berserking Aura)
*   **技能循環優先級：** 以大範圍擊倒技能起手，利用沉重的戰戟重擊追擊倒地目標，並在聚怪多目標戰鬥中啟動吸血增益維持生存。

### 守護星流派最佳化

守護星是團隊副本中堅不可摧的核心支柱。不同於以進攻為主的劍星，防禦型守護星會將屬性資源分配至「盾牌格擋」、「盾牌防禦」與「傷害減免」，以承受首領的重擊並守護脆弱的隊友。

| 屬性指標 | 劍星優先級 | 守護星優先級 | 建議附魔 / 強化 |
| :--- | :--- | :--- | :--- |
| **物理攻擊力** | S 級 | B 級 | 純攻擊力魔石 |
| **致命打擊** | S 級 | C 級 | 物理致命打擊寶石 |
| **盾牌格擋** | D 級 | S 級 | 格擋 / 防禦符文 |
| **生命力 / 韌性** | A 級 | S 級 | 生命符石 |
| **命中** | B 級 | A 級 | 命中率灌注 |

## 暗影與精準：殺星與弓星流派配裝

偵察者系依賴瞬息萬變的操作時機、敏捷身手與走位意識。皮甲提供了均衡的機動力與屬性防禦，但一旦走位失誤暴露在敵方火力下，容錯率極低。

### 殺星流派策略

殺星擅長孤立並迅速斬殺高價值目標，隨後再次隱沒於暗影之中。其流派高度依賴「攻擊速度」、「物理致命打擊」與「物理穿透」。雙持短劍能提供極致的攻擊頻率，而「短劍 / 長劍」搭配則能在目標中毒時打出更高的爆發傷害。

### 弓星流派策略

弓星憑藉超遠射程、減速牽制能力與戰術陷阱佈設，在野外遭遇戰與空中空戰中具備統治級表現。調配合格的弓星 **aion 2 class build** 著重於移動速度加成、遠程物理攻擊力以及用以擊破敵方高迴避的命中率。

| 配裝要素 | 殺星專精重點 | 弓星專精重點 |
| :--- | :--- | :--- |
| **主要核心屬性** | 物理致命打擊 & 攻擊速度 | 遠程物理攻擊力 & 物理致命打擊 |
| **次要核心屬性** | 物理穿透 & 迴避 | 移動速度 & 命中 |
| **關鍵控場技能** | 暗影步暈眩、失明毒粉 | 減速陷阱、睡眠箭、糾纏束縛 |
| **武器選擇** | 雙短劍（極速）或 短劍/長劍 | 反曲弓 / 複合弓 |
| **防禦手段** | 暗影幻影 / 偽裝潛行 | 陷阱屏障 / 後跳閃避 |

玩家實戰經驗顯示，維持最高攻擊速度門檻是殺星在短暫暈眩空檔內打出完整連招的關鍵要素。

## 奧術毀滅：魔道星與精靈星流派配裝

身著布甲的法系法師駕馭元素與召喚生物來消滅敵人。雖然防禦脆弱，但他們強大的控場能力與驚人的輸出數值，使其成為團隊副本與攻城戰中不可或缺的核心力量。

### 魔道星：元素過載

魔道星擁有全遊戲中最高的瞬間爆發潛力。在打造施法者流派時，應大量投入「魔法增幅力」與「魔法命中」。若缺乏足夠的命中，高等級首領與高裝等 PvP 對手將頻繁抵抗你的冰凍、睡眠與束縛法術。

### 精靈星：消耗與控場

精靈星透過元素精靈召喚（火、地、水、風）與密集的 DoT 減益效果來掌控戰局。其流派偏好「魔法增幅力」搭配「生命力」與「減益持續時間延長」。玩家反饋顯示，精準掌握寵物走位對於最大化防禦阻截與攻勢壓制皆至關重要。

## 神聖守護者與戰術家：治癒星與護法星流派配裝

輔助角色是每一次成功攻略團隊副本的基石骨幹。在《Aion 2》中，輔助並不意味著被動防守；當裝備配置得當時，治癒星與護法星都具備強勁的進攻能力。

### 治癒星：復原神威

治癒星是亞特雷亞最強大的主力治療者。在設計以治療為主的 **aion 2 class build** 時，請優先考慮「治癒增幅力」、「魔力上限」與「集中」（以防止遭受攻擊時施法中斷）。在單人遊戲內容中，換上附帶魔法增幅力的法杖，即可讓治癒星化身為難以擊殺的神聖輸出砲台。

### 護法星：戰鬥支援與增益

護法星兼顧前線近戰干擾與強大的全隊「真言」光環。其屬性分配傾向於「物理致命打擊」、「攻擊力」與「治癒增幅力」，使他們既能以法杖打出不俗的傷害，又能被動提升隊伍的攻擊速度、生命恢復與移動速度。

| 特性 | 純奶治癒星 | 戰鬥治癒星（單人） | 混編護法星 |
| :--- | :--- | :--- | :--- |
| **防具套裝** | 鎖甲（治癒增幅力） | 鎖甲（魔法增幅力） | 鎖甲（致命打擊 / 物理攻擊） |
| **武器** | 戰錘與盾牌 | 雙手法杖 | 雙手法杖 |
| **核心屬性** | 治療量輸出 & 魔力值 | 魔法攻擊力 & 魔法命中 | 物理攻擊力 & 物理致命打擊 |
| **團隊職責** | 全隊驅散淨化 & 爆發抬血 | 次要治療 / 副輸出 (Off-DPS) | 真言光環、擊暈控場、輔助抬血 |

## PvE 與 PvP 配裝最佳化策略

針對不同目標調整配裝至關重要，必須根據是要進入競爭激烈的深淵區域，還是刷高階副本來微調裝備。若未能針對目標內容調整屬性，角色實力將大幅受限。

### 副本與討伐戰優先級（PvE）

在 PvE 戰鬥中，穩定輸出至關重要。一旦命中達到對首領目標消除偏斜/未命中（Glancing blows）的門檻後，應將剩餘資源全數投入純粹的攻擊力或持續生存能力中。

*   達成對副本首領的 100% 命中門檻。
*   堆疊純粹的持續傷害（DoT）與瞬間爆發乘數。
*   優先提升魔力恢復速度，以避免在漫長的首領戰鬥階段出現魔力枯竭的空窗期。

### 深淵與野外戰役（PvP）

PvP 機制涵蓋了控場抗性、物理/魔法穿透，以及「韌性」（Resilience）等生存屬性。一套高效的 PvP **aion 2 class build** 需平衡爆發速度與防禦反制手段，以抵禦隱身斥候或遠程狙擊手突如其來的致命伏擊爆發。

| 屬性類別 | PvE 目標數值 | PvP 目標數值 | 最佳化說明 |
| :--- | :--- | :--- | :--- |
| **命中** | 對應副本階級達到 100% | 115%+（用以克制迴避） | 突破皮甲高敏捷迴避的關鍵 |
| **傷害穿透** | 低優先級 | 高優先級 | 穿透敵方金屬防禦與護盾防壁 |
| **韌性 / 格擋** | 輸出職業極低配置需求 | 所有職業原型皆屬關鍵 | 防止在突遭伏擊時被瞬間秒殺 |
| **控場抗性** | 僅需應對首領特定機制 | 最高優先級 | 打破連續暈眩控制（Stun-lock）與沉默連招 |

## 常見問題

### 單人練功最輕鬆的 Aion 2 職業流派是什麼？
社群回饋與玩家實測表明，劍星與護法星是單人任務練功最順暢的職業之一。兩者皆具備天生的高防禦力與穩定的自體續航恢復能力，大幅減少清怪之間的坐地休息時間。

### 烙印之石（Stigma）如何影響 Aion 2 的職業流派？
烙印之石可讓玩家獲得基礎職業技能樹之外的高階主動技能與被動天賦。裝備特定的烙印組合能大幅改變角色的專精方向——例如將防禦型治癒星轉型為強大的遠程神聖懲擊輸出者。

### 我可以自由重置並更改 Aion 2 職業流派屬性嗎？
可以。屬性點數與技能精通度可透過在各職業導師處消耗遊戲內貨幣或使用重置道具來重新分配。這種靈活性讓玩家能夠隨時維護兩套分別針對副本刷怪與深淵 PvP 交鋒的最佳化流派。

### 高難度副本的最佳隊伍配置是什麼？
傳統均衡隊伍包含一名負責前線控制的守護星、一名負責穩定續航恢復的治癒星、一名提供屬性增益與次要治療的護法星，以及三名專職輸出角色（例如魔道星、弓星與殺星），以兼顧爆發輸出與持續火力需求。
