選擇你的效忠陣營，是踏入亞特雷亞（Atreia）之前最關鍵的決定。**《AION 2》陣營（aion 2 factions）**之間的戰爭將決定你的劇情主線、家園地區，以及你在開放世界中能與哪些玩家組隊。由於伺服器設計與世界 PvP 直接與陣營忠誠度掛鉤，了解 **《AION 2》陣營**的運作方式，能確保你與公會成員不會在對立的戰場上兵戎相見。

雖然老資歷的守護者（Daeva）對天族與魔族之間的永恆宿怨早已不陌生，但這款續作在角色成長體系與伺服器領域架構上帶來了顯著的結構革新。以下為你整理關於陣營選擇、起始領地、跨伺服器衝突，以及如何挑選最合適陣營的所有必備資訊。

## 天族 vs. 魔族：世界觀背景、家園領地與外觀美學

亞特雷亞的核心衝突源於古代大崩壞（Cataclysm）時期永恆之塔（Tower of Eternity）的碎裂。當世界分裂為兩半時，這兩個陣營在截然不同的環境中演化，進而形塑出各自獨特的文化認同與外觀特徵。

```
       [ 碎裂的永恆之塔 ]
               |
      +--------+--------+
      |                 |
[ 天界：陽光普照的南方 ]   [ 魔界：冰封永夜的北方 ]
  - 主城：聖天界            - 主城：萬魔城
  - 光輝且燦爛              - 粗獷且狂野
```

### 天族：天界的光輝守護者

天族居住在天界（Elysea），也就是亞特雷亞沐浴在燦爛陽光下的南部。數百年來豐沛的光照將他們孕育為崇尚優雅的文化，外觀上帶有溫暖色調、閃耀的光輝鎧甲與潔白的羽翼。他們的社會自視為正統繼承愛昂神聖恩典的天選之民。

選擇天族的玩家將在**普埃塔（Poeta）**展開冒險旅程，這是一片寧靜祥和的翠綠鄉村，擁有茂密的森林、起伏的山丘與金黃色的林地。從那裡開始，升級路線將直接延伸至**貝爾特倫（Verteron）**，這是一個擁有宏偉大理石建築與湛藍水域的廣闊沿海與農耕區域。

### 魔族：魔界的堅韌生存者

魔族則占據著魔界（Asmodae），也就是殘破世界那寒冷黑暗的北部外殼。魔族失去了太陽的溫暖，被迫適應險惡的荒野與永無止境的昏暗。他們的美學風格體現出飽經戰火歷練的堅韌氣質，擁有更深暗的護甲色調、灰燼般的羽翼，以及純粹出於生存本能演化出的野性特徵。

魔族冒險者會在**伊斯哈魯根（Ishalgen）**展開冒險，這是一處險峻的囚禁之地，地形以冰封苔原、參差石塔與陰森遺跡為特色。隨後的升級過程將過渡到**阿爾特蓋德（Altgard）**，這是一座被茂密松林、冰凍湖泊與防禦柵欄環繞的雄偉針葉林要塞區域。

### 龍族：非玩家敵對威脅

雖然玩家必須在天族與魔族之間做出選擇，但亞特雷亞上還籠罩著第三股龐大勢力：**龍族（Balaur）**。這個龍形種族是不可遊玩的敵對陣營。在世界事件與高階副本中，龍族會動態介入戰局，時常將原本的雙方爭奪戰演變為三方混戰，使任何玩家陣營都無法輕易取得勝利。

| **陣營狀態** | 可遊玩 | 可遊玩 | 非玩家敵對勢力 |

| **新手區域** | 普埃塔 (Poeta) | 伊斯哈魯根 (Ishalgen) | 無 |
| **主要升級區域** | 貝爾特倫 (Verteron) | 阿爾特蓋德 (Altgard) | 無 |

## 跨陣營戰鬥機制與職業平衡

初次探索 **《AION 2》陣營（aion 2 factions）** 的新冒險者常問的一個問題是：是否有某個陣營擁有更優越的種族天賦、隱藏屬性優勢或高階戰鬥技能？在本作的全球發行版本中，雙方的戰鬥數值平衡是完全鏡像對稱的。

任何一方都不具備獨特的數值優勢或更高階的種族技能。天族與魔族皆可完整體驗首發的所有八種職業，並且維持完全相同的基礎屬性、技能循環、傷害加成倍率以及冷卻時間。在天界培養的劍星，與在魔界受訓的劍星造成的基礎傷害與控場持續時間完全一致。

這種平衡性確保了競爭激烈的 PvPvE、深淵要塞戰以及競速排行榜的勝負，完全取決於玩家的操作技巧、裝備配置與團隊協同作戰，而非內建的陣營不平衡。

角色自訂功能也賦予玩家全面的創作自由。雖然世界觀設定將天族與光明美學連結、魔族與幽暗主題連結，但遊戲內擴展的捏臉系統能讓你自由調整膚色、眼神倒影、髮型輪廓與體型，無論在哪個陣營都不受限制。

## 伺服器架構與陣營鎖定機制

全球伺服器基礎架構在處理陣營歸屬的方式上，與傳統開放世界 MMORPG 大不相同。在過去的傳統設計中，敵對雙方通常共用同一個伺服器，往往導致嚴重的陣營人口失衡，並扭曲拍賣場經濟。

在全球版本中，**每個伺服器完全僅隸屬於單一陣營**。啟動遊戲時，你需要選擇所在區域、挑選陣營，接著再選擇專為該陣營開放的專屬伺服器。

```
[ 地區選擇 (NA / EU / ASIA) ]
               |
      +--------+--------+
      |                 |
 [ 選擇：天族 ]   [ 選擇：魔族 ]
      |                 |
[ 伺服器：天族 A ] [ 伺服器：魔族 B ]
      |                 |
      +--------+--------+
               |
     [ 動態深淵配對機制 ]
```

這種單一陣營伺服器架構帶來了幾項核心優勢：

* **本土大陸絕無陣營失衡：** 在一般的開放世界升級過程中，你的本土領地永遠不會遭到敵方壓倒性優勢人口的惡意屠殺。
* **與好友安全組隊：** 位於同一個伺服器的玩家皆必定為友好盟友，徹底消除好友之間誤擊或受干擾的情況。
* **動態領域配對系統：** 為了提供競爭性內容，遊戲會將每個天族伺服器與專屬的魔族伺服器進行動態配對。這些配對會定期更新，以維持活躍且勢均力敵的對抗環境。

由於伺服器具有陣營鎖定機制，若要與好友共同遊玩，你們必須選擇**相同的陣營**與**相同的伺服器名稱**。如果你的團隊分散在天族伺服器與魔族伺服器，你們將只能在跨服戰場上成為互為死敵的對手。在敲定公會入駐計畫前，你可以直接透過 [NCSoft 官方網站](https://www.plaync.com) 追蹤官方伺服器配對時程表。

| 架構特點 | 傳統混合伺服器模式 | 《AION 2》單一陣營伺服器模式 |
| :--- | :--- | :--- |
| **伺服器歸屬** | 雙方陣營共同使用 | 100% 專屬於單一陣營 |
| **開放世界升級** | 時常遭受高階敵對玩家越界獵殺 | 新手區本土進程安全無虞 |
| **陣營人口平衡** | 單一伺服器常出現 70/30 極端失衡 | 透過配對伺服器動態平衡 |
| **公會統籌協調** | 朋友可能誤選敵對陣營造成困擾 | 同伺服器內所有友方玩家組隊流程簡便 |
| **跨陣營交戰體驗** | 僅侷限於本地伺服器邊界之內 | 透過多伺服器深淵戰場大幅擴展交戰規模 |

## PvPvE 戰事：深淵與時空裂縫

儘管本土伺服器受到了保護，但 **《AION 2》陣營** 之間的衝突依然是獲取後期獎勵、深淵點數（Abyss Points）與高階軍階裝備的核心驅動力。開放世界戰火主要透過兩大機制展開：深淵（The Abyss）與時空裂縫（Spacetime Rifts）。

### 深淵：真正的三維空戰

深淵坐落於亞特雷亞破碎的核心地帶，作為連接成對的天族與魔族伺服器的共享 PvPvE 戰場。在深淵內部，飛行限制將被解除，玩家可以在漂浮的以太浮島、古代要塞和神器防衛塔之間，展開無拘無束的空中大戰。

掌控深淵要塞可為全伺服器帶來經濟加成、解鎖專屬高階商人，並賦予陣營全體 PvE 屬性增益。然而，要塞攻防戰絕非單純的兩方角力。龍族艦隊會定期在關鍵防禦虛弱期大舉入侵，同時攻擊雙方玩家陣營，迫使指揮官在全力進攻與防守整頓之間做出即時抉擇。

```
       [ 爭奪中的深淵要塞 ]
              /     |     \
             /      |      \
 [ 天族部隊 ]       |       [ 魔族部隊 ]
                    |
           [ 龍族大舉入侵 ]
```

### 時空裂縫：高風險滲透突襲

對於偏好游擊戰術而非大規模要塞軍團戰的玩家，**時空裂縫**提供了非對稱的世界 PvP 機制。裂縫是不穩定的次元傳送門，會在貝爾特倫、阿爾特蓋德及過渡地區隨機開啟。

穿過裂縫會將突擊小隊直接傳送進敵對陣營的本土腹地。社群情報指出，進行裂縫突襲主要有三大戰術目的：

* **PvE 狩獵與採集：** 敵方大陸專屬的稀有怪物與區域性採集資源，可用於取得獨特的製作圖紙。
* **賞金狩獵：** 在敵方本土領地擊敗敵對玩家，可獲得更多陣營貨幣與軍階積分。
* **防守攔截：** 當敵對裂縫開啟時，本土伺服器玩家會收到區域天空警報，能迅速集結防守小隊，在入侵者抵達區域任務據點前將其殲滅。

| 戰鬥模式 | 地點 | 隊伍規模 | 是否允許飛行 | 主要目標 |
| :--- | :--- | :--- | :--- | :--- |
| **深淵要塞攻防戰** | 核心深淵 | 團隊 (48–100+ 人) | 全方位 3D 空中戰鬥 | 攻佔城堡並奪取神器聖物 |
| **時空裂縫突襲** | 敵對陣營本土 | 小型小隊 (1–6 人) | 限制飛行 / 僅限滑翔 | 游擊 PvP、掠奪敵方物資、刷賞金 |
| **神器前哨遭遇戰** | 深淵外圍 | 小隊 (6–12 人) | 全方位 3D 空中戰鬥 | 啟動戰術戰場增益以支援要塞戰 |
| **裂縫防守戰** | 友方本土 | 開放世界防禦 | 限制飛行 / 僅限滑翔 | 攔截敵方滲透小隊並封鎖裂縫傳送門 |

由於 **《AION 2》陣營** 之間的戰鬥力在機制上是完全平衡的，你的選擇重點應落在社交關係、外觀偏好以及世界區域的美學風格。


在做出決定前，請審慎評估以下實用考量：

1. **優先與好友協調整合：** 在伺服器完全由單一陣營獨佔的 MMORPG 中，你無法跨越陣營邊界進行交易、密語聊天或組隊。在創角前，請務必先與親友確定好陣營與伺服器。
2. **評估視覺景觀環境：** 你將花費數百小時探索所屬陣營的家園領地。如果你喜歡明亮天空、金色沙灘與古典建築，請選擇天族；如果你更享受幽暗松林、風雪呼嘯的峰巒與哥德式暗黑要塞，請選擇魔族。
3. **公會文化與玩家生態：** 玩家社群往往會形成獨特的次文化風氣。社群報告顯示，各大主力競賽 PvP 公會通常在上市前數個月就已經選定特定的配對伺服器進行集結。多關注活躍的社群 Discord 能幫助你找到契合自身遊戲風格的伺服器。

| 玩家核心考量 | 推薦陣營 | 關鍵原因 |
| :--- | :--- | :--- |
| **偏好光明白晝風格的世界設計** | **天族** | 享有普埃塔、貝爾特倫以及陽光明媚的海岸建築 |
| **偏好暗黑奇幻與荒野求生氛圍** | **魔族** | 享有伊斯哈魯根、阿爾特蓋德與沉靜肅穆的北方生態群落 |
| **專注與固定好友團隊共同遊玩** | **配合團隊決定** | 嚴格的陣營鎖定無法支援跨陣營組隊邀請 |
| **極致追求數據的最佳化玩家** | **任一陣營皆可** | 各職業技能、基礎屬性與戰鬥機制完全一致 |
| **專注於開放世界游擊 PvP 戰鬥** | **任一陣營皆可** | 雙方均享有相同的時空裂縫與配對深淵戰場使用權限 |

不妨花點時間瀏覽美術設定圖、與你的遊戲夥伴深入討論，並再次確認你們要入駐的伺服器。無論你最終選擇效忠碎裂世界的哪一方，自踏入大地的第一天起，爭奪永恆之塔的戰役便需要你的全力以赴。

## 常見問題

### 《AION 2》各陣營的職業有所不同嗎？
沒有差別。無論是天族還是魔族，首發的全部八個職業在基礎屬性、戰鬥技能、傷害公式與機制表現上皆完全一致。陣營選擇在 PvE 或 PvP 中均不會提供任何數值或競爭上的差異優勢。

### 天族與魔族角色可以在同一個隊伍中一起遊玩嗎？
不行。來自對立 **《AION 2》陣營** 的角色無法組隊、交易道具、加入同一個公會，也無法在開放世界聊天頻道中溝通。雙方僅能在深淵或透過時空裂縫等共享交戰區域中，以敵對戰鬥人員的身份相互互動。

### 《AION 2》的陣營伺服器運作機制為何？
在全球版本中，每個伺服器完全僅隸屬於單一陣營。玩家需選擇所在區域、挑選陣營，然後從該陣營的專屬伺服器清單中選擇其一。天族伺服器會動態與魔族伺服器進行配對，以提供勢均力敵的跨服 PvPvE 競技體驗。

### 建立角色後可以更換陣營嗎？
角色在創建時即綁定所選陣營。若想體驗敵對陣營，你必須在專屬於該陣營的伺服器上建立新角色。在確定你的起步伺服器前，請務必與公會及好友團隊仔細核對最終計畫。
