## キャラクター作成における基本クラス選択

初期段階の**『Aion 2』キャラクタークリエイト**において、クラス選択は旅全体の根幹を決定づけます。本作ではファンに愛された伝統の8大クラス体系が復活しており、前衛の堅牢なタンク、敏捷なアタッカー、遠距離の術者、そして不可欠な支援役へと洗練されて分類されています。

後半のゲーム進行まで特徴が曖昧なままのMMORPGとは異なり、『Aion 2』ではキャラメイク画面の段階で各クラスのテーマが明確に提示されます。外見を確定する前に、防具のシルエット、象徴的な戦闘スタンス、攻撃モーションなどをプレビュー可能です。

### 基本となる8大クラス

クラスラインナップは、アタッカー、タンク、ハイブリッドヒーラーの間で見事にバランスが取れています。「ソードウィング（Gladiator）」のような近接ファイターは、圧倒的な威力を誇るハルバードや大剣を振るって広範囲を制圧し、「シールドウィング（Templar）」は集団戦において不屈の盾として味方を守護します。「シャドウウィング（Assassin）」と「ボウウィング（Ranger）」は物理ダメージ枠として君臨し、それぞれ隠密からの奇襲や正確無比な弓撃を駆使します。

魔法を操るクラスは元素の力を引き出します。「スペルウィング（Sorcerer）」は強力な瞬間火力の呪文を放ち、「スピリットウィング（Spiritmaster）」は精霊を召喚して敵に弱体効果を与え、戦局をコントロールします。そして支援職として、「キュアウィング（Cleric）」は専任の治療とパーティのリカバリーに長けており、「チャントウィング（Chanter）」は前線での近接戦闘能力に加え、パーティ全体を強化するマントラやバフで味方を強力にサポートします。

## 勢力（種族）の違いと初期の出自

勢力（種族）の選択は、キャラクターのアイデンティティを決定づける最重要要素です。陽光に祝福された「天族（Elyos）」に忠誠を誓うか、過酷なオードに鍛え上げられた「魔族（Asmodians）」を選ぶかによって、外見の印象、世界観のトーン、そして翼のビジュアルが劇的に変化します。

システム上の勢力バランスは調整が重ねられていますが、視覚的な差異は際立っています。天族のデザインはクリーンな輪郭、透き通るような白肌、純白の鳥のような羽毛が特徴です。対する魔族は、ダークトーンのカラーパレット、鋭い爪、発光する背中のたてがみ、漆黒の翼など、野性味あふれる特徴を備えています。

| 勢力要素 | 天族（Elyos）のビジュアル特徴 | 魔族（Asmodians）のビジュアル特徴 |
| :--- | :--- | :--- |
| **主たる光彩・色彩** | 温かみのあるゴールド、神秘的な白、鮮やかな青 | クールなブルー、深紫の影、真紅のアクセント |
| **翼のデザイン** | 光り輝く天使のような羽毛 | レザー調の質感、カラスのような漆黒の羽 |
| **固有の身体的特徴** | 滑らかな四肢、正統派の英雄的シルエット | 爪のある手足、背中の体毛/たてがみ、発光する瞳 |
| **初期スタート環境** | 陽光降り注ぐ聖所、緑豊かな渓谷 | 氷河の峡谷、険しい岩山、黄昏のツンドラ |
| **全体の世界観トーン** | 神聖な秩序、気品ある伝統 | 過酷な環境での生存本能、荒々しい闘志 |

**『Aion 2』キャラクタークリエイト**を進める際、選択した勢力によって環境光の反射の仕方が変わります。天族の肌は暖かみのある昼光を美しく反射し、魔族の肌質は暗がりで映えるクールで玉虫色のようなハイライトを帯びます。

## キャラクター作成の手順別ステップガイド

**『Aion 2』キャラクタークリエイト**を計画的に進めることで、後から高価な外見変更チケットを消費する事態を防ぐことができます。焦って作成を完了してしまうと、声のトーンの違和感、不自然な走行モーション、武器の突き抜けなどに悩まされることになりかねません。

以下の手順に沿って、効率よく理想の英雄を作成しましょう。

| ステップ | フェーズ | 実施事項 |
| :--- | :--- | :--- |
| **ステップ 1** | 勢力とクラスの決定 | 天族または魔族を選択し、基本となるクラスを選択する。 |
| **ステップ 2** | ベースプリセットの選択 | 好みの骨格に近いベースフェイスモデルを探す。 |
| **ステップ 3** | 詳細な顔の造形 | 目の形状、口の幅、鼻の傾き、肌のキメなどを微調整する。 |
| **ステップ 4** | 体型スケール＆シルエット | 防具プレビューを見ながら、身長、手足の太さ、肩幅のバランスを取る。 |
| **ステップ 5** | コスメ＆ボイスの確認 | 髪色、瞳のグラデーション、メイク、傷跡、ボイスパターンを設定する。 |

特に「ステップ6」は念入りに行いましょう。静止したスタジオポーズでは見えなかった武器納刀時の突き抜けや、走行アニメーション時の不自然さがここで浮き彫りになります。

## アトレイアへ降り立つ前に知っておくべき上級者向け作成のコツ

シリーズのベテランプレイヤーたちは、審美眼とゲームプレイ上の利便性の両方を意識して**『Aion 2』キャラクタークリエイト**に取り組みます。長年のMMOの歴史が示す通り、外見デザインは時にプレイヤーの操作快適性やフィールドでの視認性に影響を与えるからです。

初期の先行テストにおけるコミュニティ報告によると、PvPにおいてキャラクターの身長が攻撃射程や当たり判定（ヒットボックス）の大きさを根本的に変えることはありません。しかし、極端なサイズ調整はカメラ視界に影響を及ぼします。巨大なモデルは狭いダンジョンの通路で画面占有率が高くなり、極端に小柄なモデルは混戦時に足元の位置把握が難しくなる場合があります。

公式の展開情報やサーバー稼働スケジュールについては、地域ごとの最新情報を随時公開している[NCSoft公式ポータル](https://www.ncsoft.com)で確認できます。

| 設定項目 | 発生し得る問題 | 推奨される解決策 |
| :--- | :--- | :--- |
| **極端な身長スライダー** | カメラが引きすぎたり、低い天井にカメラがめり込む | 身長スライダーは中央値の35%〜65%の範囲に収める。 |

| **肌の過度な光沢** | 真昼の太陽光下でテカリすぎたり不自然に反射する | 肌の粗さ（ラフネス）スライダーを標準的なレベル（40〜60%）に設定する。 |
| **ボイスの極端なピッチ変更** | 戦闘中の気合声や被弾時のボイスが機械的に歪む | エディターを離れる前に、すべての戦闘ボイスサンプルを試聴する。 |
| **カスタムデータの消失** | 予期せぬ切断により数時間のスライダー調整データが消える | 作成作業中、こまめに「プリセットデータ保存」ボタンを押す。 |

### プリセットとデータのエクスポート機能

最新エンジンにおける最も便利な機能の一つが、プリセットのエクスポートツールです。プレイヤーは調整した正確なスライダー数値をローカル設定ファイルに直接保存したり、テキスト形式のプリセットコードとしてコピーしたりできます。

この機能を活用すれば、テスト段階をまたいでデザインを共有したり、記憶を頼りに再調整することなく別サーバーにお気に入りの外見を再現できます。最終決定を下す前に、気に入った外見のバリエーションを少なくとも2つ保存しておくことをおすすめします。

## 『Aion 2』キャラクタークリエイトに関するよくある質問（FAQ）

### キャラクター作成完了後に外見を変更することはできますか？
はい、変更可能です。ゲーム内の消費アイテムショップや特別イベント報酬などで手に入る「外見変更チケット」を使用すれば、後から外見を再調整できます。ただし、所属勢力やクラスの選択は変更できないため、これらは初期作成時に慎重に選んでください。

### キャラクターの体格は当たり判定や移動速度に影響しますか？
プレイヤーの体験や最新エンジンビルドの検証によると、キャラクターの体格差によって当たり判定（ヒットボックス）や基本移動速度が変わることはありません。PvPアリーナやオープンワールドの時空の裂け目（リフト）での公平性を保つため、すべてのキャラクターで衝突判定が標準化されています。

### キャラクター作成中にスライダー設定を保存することはできますか？
はい、キャラメイク画面には専用のプリセットエクスポートボタンが用意されています。スライダー設定プロファイルをローカルドライブに保存しておけば、別サーバーですぐに読み込んだり、フレンドと共有したり、キャラクターを作り直す際に即座に復元したりできます。

### サービス開始時から8クラスすべてが利用可能ですか？
はい、基本クラスとしてソードウィング、シールドウィング、シャドウウィング、ボウウィング、スペルウィング、スピリットウィング、キュアウィング、チャントウィングの全8種が用意されています。レベル制限のあるディーヴァ転職クエストを待つことなく、キャラクター作成画面で直接メイン専門クラスを選択できます。
